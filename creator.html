A focused set of building blocks.

The palette is intentionally understandable and limited, so the exported behavior stays inside the actions the editor exposes.

Choose an event

Begin when the classroom block is placed or when a player comes near it in the world.

Add visible actions

Show a message, give an item, wait, change the block, or update a project variable.

Use logic and repetition

Add if conditions, nearby sensors, comparisons, repeat blocks, and variables to make the interaction respond.

Preview the classroom object

Name the block, choose a garden, stone, wood, or glass style, and organize it under Classroom, Science, or Activity.

Build, preview, export, and use.

Creator handles the project files so the educator can concentrate on what students will encounter.

  1. 1

    Name the classroom project

    Choose a clear block name, category, and visual style for the activity.

  2. 2

    Connect the behavior blocks

    Drag an event into the workspace and place actions, logic, loops, or variables beneath it.

  3. 3

    Check the live preview

    Review the classroom object and make sure its label and style fit the lesson.

  4. 4

    Export the OpenClassCraft mod

    Creator writes the mod configuration, project data, and generated Lua into one self-contained folder.

Safe by keeping the available actions explicit.

Creator does not accept arbitrary code in the visual project. It generates behavior only from the events, actions, logic, loops, sensors, and variables that are available in its palette.

  • No blank code editorThe workflow begins with understandable visual blocks.
  • Controlled action setProjects stay within the behavior the palette can express.
  • Portable outputEach export is a self-contained OpenClassCraft mod folder.
