# OpenClassCraft website

built with plain HTML, CSS, and JavaScript. The visual assets in `assets/images` are sourced from the adjacent OpenClassCraft project.


## Files

- `index.html` — the broader OpenClassCraft classroom-platform overview
- `teacher-console.html` — dedicated Teacher Console product page
- `creator.html` — dedicated OpenClassCraft Creator product page
- `downloads.html` — operating-system downloads, installation directions, checksums, and version history
- `styles.css` — readable organization-style layout and responsive visual system
- `script.js` — sticky header and responsive navigation behavior
- `assets/images` — OpenClassCraft product artwork
