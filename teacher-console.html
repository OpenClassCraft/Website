Built around real classroom tasks.

The Console handles the organization that should not have to happen inside the student-facing world.

Prepare lessons

Create a title, choose a subject, write learning objectives, and define checkpoints students can complete during the activity.

Organize the class

Maintain student and group lists, import a CSV class list, and assign each group to a lesson and starter world.

Follow learning progress

Track completed checkpoints, add teacher notes, and export a straightforward CSV report after the session.

Back up local records

Save and restore JSON backups without depending on a cloud account or an external classroom service.

From lesson plan to local classroom world.

The bridge is designed for a teacher hosting OpenClassCraft and the Console on the same computer.

  1. 1

    Create the lesson

    Add the learning objective and the checkpoints that matter for this activity.

  2. 2

    Assign a group and world

    Choose which class group receives the lesson and where their activity begins.

  3. 3

    Start the local lesson bridge

    Export the generated settings, add them to the teacher host, and synchronize the active lesson.

  4. 4

    Review and export

    Record completed checkpoints, add notes, and export the class report when the activity is finished.

Designed to keep classroom data local.

The bridge listens only on the teacher’s own computer and requires a generated token. It shares the selected lesson plan with the local OpenClassCraft host; it does not send student lists, reports, or backups into the game world.

  • Loopback-only bridgeListens on 127.0.0.1 rather than the wider network.
  • Limited lesson payloadOnly the active plan and checkpoint events are exchanged.
  • Local recordsStudent details, notes, reports, and backups remain on the teacher’s computer.
