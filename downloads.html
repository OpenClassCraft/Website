Installation directions

Keep the extracted folders intact. Moving or deleting runtime files can prevent OpenClassCraft from starting.

Windows ready-to-play build

  1. Download Windows-Build.zip.
  2. Extract the entire ZIP archive to a normal folder such as Documents or Desktop.
  3. Open the extracted folder, then open bin\Release.
  4. Run openclasscraft.exe.
  5. Keep the DLL files beside the executable. Do not run the executable from inside the ZIP preview.

Linux, macOS, and BSD manual setup

  1. Install the current stable version of Luanti for your operating system.
  2. Download the OpenClassCraft build files and extract them.
  3. Inside the extracted project, locate games/luanti_edu.
  4. Open Luanti, go to About, and choose Open User Data Directory. Create a games folder there if one does not exist.
  5. Copy the complete luanti_edu folder into that games folder, then restart Luanti.
  6. Select OpenClassCraft when creating a world.

This manual route is useful for testing the game content. The complete branded application and custom engine experience may require compiling the supplied build files.

Android manual setup

  1. Install Luanti from the official Android download choices.
  2. Download and extract Build-Files.zip.
  3. Copy games/luanti_edu into the Luanti user-data games folder using a file manager with storage access.
  4. Restart Luanti and select OpenClassCraft when creating a world.

Android storage restrictions differ by device. If the app data folder cannot be accessed, a standalone APK or ContentDB package will be needed; neither is currently published.

Explore your first classroom world

  1. Start OpenClassCraft and create or select a world.
  2. Open the inventory and choose from the Classroom, Chemistry, Creative, or Coding tools.
  3. Place a guide NPC, board, lesson planner, chemistry lab, or checkpoint to shape an activity.
  4. Build and explore together; use visual programming and the robot when they support the lesson.
